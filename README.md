Checks and looks for sneakers, describes the inventory number and gives a response depending on what you input into the console


How to Run

Run the "inventory_checker.py" file in a python based system

Enter the name of the shoe and the amount when the prompt is given.

What it does

This program is designed to tell information depending on the quantity of the shoe that is given
Depending on what is given the system can give 3 outputs
- Out of stock
- Running Low
- Sufficiently stocked
